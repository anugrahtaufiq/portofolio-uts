# Personal Portfolio Website

Proyek ini adalah tugas pembuatan website portofolio pribadi yang dideploy secara online. Website ini merangkum pengalaman kerja saya di bidang perhotelan serta proyek akademik saya sebagai mahasiswa Sistem Informasi.

## 🚀 Fitur & Teknologi
- **Teknologi:** HTML5, CSS3 (Custom Abstract Background), JavaScript.
- **Konsep Desain:** Modern, Clean, & Professional dengan aksen warna Biru-Ungu.
- **Responsive:** Optimal untuk tampilan desktop.

## 🛠️ Cara Menjalankan Secara Lokal
1. Clone repository ini.
2. Pastikan file foto berada di folder `/img`.
3. Buka `index.html` di browser pilihan Anda.
